# Call of chattY Documentation

Central documentation index for the Three.js tactical FPS project.

## Documents

- `PLAN.md` — product roadmap, milestones, acceptance gates.
- `PROGRESS.md` — current implementation status and evidence.
- `ARCHITECTURE.md` — runtime, rendering, gameplay and networking architecture.
- `GAMEPLAY.md` — controls, combat loop, AI and player systems.
- `MULTIPLAYER.md` — client/server protocol and deployment notes.
- `DEPLOYMENT.md` — local, GitHub Pages and production hosting.
- `QA.md` — validation matrix and /loop process.
- `RELEASE.md` — release checklist and rollback procedure.
- `CHANGELOG.md` — human-readable version history.

## Evidence policy

Progress percentages are engineering maturity estimates, not claims of commercial AAA parity. A true blind comparison requires synchronized reference captures from both products under controlled conditions.
